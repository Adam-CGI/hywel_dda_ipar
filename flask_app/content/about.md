# About the Hywel Dda Document Intelligence System

## Overview
The Hywel Dda Document Intelligence System is a **pilot platform** designed to help teams quickly find and retrieve information from NHS IPAR (Integrated Performance & Assurance Report) documents. Instead of manually searching through multiple PDF files, users can ask questions and receive relevant answers with direct citations to the source documents.

## What This System Does

**Intelligent Document Search**  
Upload IPAR reports and search them using natural language questions. The system understands the meaning of your query, not just keywords, to find the most relevant information.

**Transparent Citations**  
Every answer includes direct references to specific pages in source documents, with visual thumbnails, so you can verify the information and access the original context.

**Smart Duplicate Detection**  
The system automatically identifies when documents have already been uploaded, preventing duplication and maintaining a clean document library.

**Secure Document Management**  
All documents are stored securely in the cloud with full audit trails showing when documents were uploaded, by whom, and what processing occurred.

## What This System Is Not

**Not a Clinical Decision Tool**  
This system assists with finding information in reports but does not provide medical advice or clinical decision support. Professional judgement remains essential.

**Not a Patient Data System**  
The system is designed exclusively for organizational performance reports. It does not store or process individual patient records or identifiable patient information.

**Not Yet Production-Ready**  
This is a **pilot deployment** for evaluation purposes. The system is being tested and refined before full organisational rollout.

**Not a Replacement for Reading**  
The system helps you find relevant sections quickly, but important decisions should always be based on reviewing the full source documents.

## Current Phase: Pilot Evaluation

This pilot helps us understand:
- How teams search for information in IPAR documents
- What types of questions are most valuable
- How the system can best support decision-making workflows
- What improvements are needed before production deployment

## Moving Toward Production

Based on pilot learnings, the production system will include:
- **Enhanced access controls** with role-based permissions
- **Expanded document types** beyond IPAR reports
- **Advanced analytics** to identify trends and patterns across reports
- **Improved performance** with faster search and processing
- **Integration** with existing Hywel Dda systems and workflows

## Data Security & Governance

- All data is stored in secure Azure cloud services.
- Complete audit logs track all system activities
- Access is controlled and monitored
- No patient-identifiable information is to be processed.
- All AI responses include source citations to prevent misinformation

_This is a pilot system under active development. Capabilities and features are subject to change._
